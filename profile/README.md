# Bifröst Orbit

One sign-in for every tool your team uses, with satellites for content, hiring, travel, shops, bookings, reviews and analytics. Hosted in the EU.

## CMS Orbit

The headless CMS. Every SDK reads the same delivery API, and `npx cms-orbit generate` writes types for each of them from your website's schema.

| Language | Package | Repository |
| --- | --- | --- |
| JavaScript and TypeScript | [`@bifrost-orbit-cms/sdk`](https://www.npmjs.com/package/@bifrost-orbit-cms/sdk) on npm | [Guide](https://docs.bifrostorbit.com/cms/developers/sdk) |
| PHP | `bifrost-orbit/cms-sdk` on Packagist | [cms-sdk-php](https://github.com/bifrost-orbit/cms-sdk-php) |
| Swift | Swift Package Manager | [cms-sdk-swift](https://github.com/bifrost-orbit/cms-sdk-swift) |
| Kotlin | `com.bifrostorbit:cms-sdk` on Maven Central | [cms-sdk-kotlin](https://github.com/bifrost-orbit/cms-sdk-kotlin) |

### GitHub Action

[cms-orbit-action](https://github.com/bifrost-orbit/cms-orbit-action) keeps your website's types in sync with your space: it opens a pull request when the schema changes, or fails a pull request whose types are out of date.
