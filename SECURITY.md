# Security

Please don't report security problems in public issues.

## Report a vulnerability

Use **Report a vulnerability** on the repository's **Security** tab, or email support@bifrostorbit.com with "Security" in the subject. Tell us which repository and version, what an attacker could do, and how to reproduce it.

We reply within three working days, keep you updated while we fix it, and credit you when the fix is out if you'd like.

## Supported versions

We fix security problems in the latest release of each SDK and starter. Please update before reporting.
