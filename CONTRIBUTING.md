# Contributing

Thank you for helping. These SDKs and starters are published from the Bifröst Orbit monorepo, so changes are made there and then copied here.

- **Found a bug?** Open an issue with the version, what you expected and what happened. A small example helps us most.
- **Have an idea?** Open a feature request and tell us what you're trying to do.
- **Want to send a fix?** Pull requests are welcome. Keep them small and focused. We'll apply the change in the monorepo, credit you, and close the pull request when the next version is published.

Please follow our [code of conduct](CODE_OF_CONDUCT.md).
